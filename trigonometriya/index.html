8Trigonometrik deňlemeler

Islendik trigonometrik deňleme ahyrsoňy iň ýönekeý deňlemelere — sin x = a, cos x = a, tg x = a — getirilýär. Olaryň umumy çözgüdi (n — islendik bitin san):

x=(−1)narcsin⁡a+πn, n∈Zx=(-1)^n\arcsin a+\pi n,\ n\in\mathbb{Z}x=(−1)narcsina+πn, n∈Z

|a| > 1 bolsa — çözgüt ýok. sin x = 0 ⇒ x = πn; sin x = 1 ⇒ x = π/2 + 2πn.

cos x = 0 ⇒ x = π/2 + πn; cos x = 1 ⇒ x = 2πn; cos x = −1 ⇒ x = π + 2πn.

Çözmegiň usullary

  1. Ornuna goýma: 2sin²x − 3sin x + 1 = 0 deňlemede t = sin x alyp, kwadrat deňleme çözülýär (|t| ≤ 1 barlanýar).
  2. Köpeldijilere dagytmak: sin 2x = cos x ⇒ cos x(2sin x − 1) = 0 ⇒ cos x = 0 ýa-da sin x = 1/2.
  3. Bir jynsly deňlemeler: sin²x − 3sin x cos x + 2cos²x = 0 deňlemäni cos²x-a bölüp, tg x boýunça kwadrat deňleme alynýar.
  4. Kömekçi burç: asin⁡x+bcos⁡x=a2+b2 sin⁡(x+φ)a\sin x+b\cos x=\sqrt{a^2+b^2}\,\sin(x+\varphi)asinx+bcosx=a2+b2​sin(x+φ), bu ýerde cos φ = a/√(a² + b²), sin φ = b/√(a² + b²).
  5. Bir atly funksiýalar: sin A = sin B ⇔ A = B + 2πn ýa-da A = π − B + 2πn; cos A = cos B ⇔ A = ±B + 2πn.
