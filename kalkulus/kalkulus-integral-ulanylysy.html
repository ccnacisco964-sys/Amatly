7. Integralyň ulanylyşy

Bu sapakda kesgitli integralyň kömegi bilen egriler arasyndaky meýdany, aýlanma jisimleriň göwrümini, funksiýanyň ortaça bahasyny we egriniň uzynlygyny hasaplamagy öwrenersiň.

7.1 Düşünje

Kesgitli integral — kiçijik bölekleriň jemi. Oblasty inçe zolaklara (giňligi dx) bölýäris, her zolagyň meýdanyny, göwrümini ýa-da uzynlygyny hasaplaýarys, olary goşýarys we zolaklary barha inçe edýäris. Şol bir pikir ähli ulanyşlarda gaýtalanýar.
  • Egriler arasyndaky meýdan: zolagyň beýikligi = ýokarky egri − aşaky egri.
  • Aýlanma jisimiň göwrümi: zolagy x oky daşynda aýlasak disk (ýa-da halka — washer) alynýar; y oky daşynda aýlanma üçin gabyk (shell) usuly ulanylýar.
  • Ortaça baha: funksiýanyň aralykdaky "deňleşdirilen" bahasy.
  • Egriniň uzynlygy: kiçijik ýaýy gipotenuza hökmünde alýarys: √(dx² + dy²).

7.3 Mysal we ädimme-ädim çözgüt

Mysal 1 (meýdan): y = x we y = x² egrileriň arasyndaky meýdany tap.
  1. 1-nji ädim: Kesişme: x = x² → x(x − 1) = 0 → x = 0 we x = 1.
  2. 2-nji ädim: [0; 1]-de x ≥ x² (mysal: x = 0,5 üçin 0,5 ≥ 0,25), ýokarky egri y = x.
  3. Netije: S = ∫01 (x − x²) dx = [x²/2 − x³/3]01 = 1/2 − 1/3 = 1/6.
Mysal 2 (göwrüm): y = √x egrisiniň [0; 4] aralygyny x oky daşynda aýlandyryp alnan göwrümi tap.
  1. 1-nji ädim: Disk usuly: V = π ∫04 (√x)² dx.
  2. 2-nji ädim: (√x)² = x, şonuň üçin V = π [x²/2]04.
  3. Netije: V = π · 8 = 8π ≈ 25,13.
Mysal 3 (ortaça baha): f(x) = x² funksiýanyň [0; 3] aralykdaky ortaça bahasyny tap.
  1. 1-nji ädim: ∫03 x² dx = [x³/3]03 = 9.
  2. 2-nji ädim: fort = 9 / (3 − 0) = 3.
  3. Barlag: x² = 3 → c = √3 ≈ 1,73 ∈ [0; 3]: funksiýa şol nokatda ortaça baha deň bolýar.
Mysal 4 (uzynlyk): y = (2/3)·x3/2 egrisiniň [0; 3] aralykdaky uzynlygyny tap.
  1. 1-nji ädim: f′(x) = (2/3)·(3/2)·x1/2 = √x.
  2. 2-nji ädim: 1 + f′² = 1 + x, şonuň üçin L = ∫03 √(1 + x) dx.
  3. Netije: L = [(2/3)(1 + x)3/2]03 = (2/3)(8 − 1) = 14/3 ≈ 4,67.

7.4 Interaktiw kalkulýator

Integralyň ulanylyş hasaplaýjysy

f(x) (we islege görä g(x)) hem-de [a; b] aralygy giriz: egriler arasyndaky meýdany, x oky daşynda aýlanma göwrümini, f-iň ortaça bahasyny we f egrisiniň uzynlygyny Simpson usuly bilen hasaplaýar. Grafikde meýdan reňklenýär, gyzyl bölünen çyzyk — ortaça baha.

Mysallar:
g(x)-i boş goýsaň, ikinji egri x oky (g = 0) hasaplanýar. Göwrüm formulasy 0 ≤ g ≤ f bolanda dogry; uzynlyk diňe f egrisi üçin hasaplanýar. π üçin pi ýaz.

7.5 Maşk

1. y = x² we y = 4 egrileriň arasyndaky meýdany tap — Jogaby görkez

Kesişme: x² = 4 → x = ±2. S = ∫−22 (4 − x²) dx = [4x − x³/3] = (8 − 8/3) − (−8 + 8/3) = 32/3 ≈ 10.67.

2. y = x² egrisiniň [0; 2] aralygyny x oky daşynda aýlandyryp alnan göwrümi tap — Jogaby görkez

V = π∫02 x⁴ dx = π · 32/5 = 32π/5 ≈ 20.11.

3. y = x we y = x² (0 ≤ x ≤ 1) arasyndaky bölegi x oky daşynda aýlandyr. Göwrüm? — Jogaby görkez

Washer: V = π∫01 (x² − x⁴) dx = π(1/3 − 1/5) = 2π/15 ≈ 0.419.

4. f(x) = sin x funksiýanyň [0; π] aralykdaky ortaça bahasy? — Jogaby görkez

∫0π sin x dx = 2, şonuň üçin fort = 2/π ≈ 0.637.

5. y = 3x + 1 çyzygynyň [0; 2] aralykdaky uzynlygy? — Jogaby görkez

f′ = 3, L = ∫02 √(1 + 9) dx = 2√10 ≈ 6.32 ((0; 1) we (2; 7) nokatlaryň arasyndaky aralyk bilen gabat gelýär).

6. y = x³ we y = x egrileriň arasyndaky meýdany tap — Jogaby görkez

Egriler üç nokatda kesişýär: x = −1; 0; 1. [−1; 0]-da x³ ≥ x, [0; 1]-de x ≥ x³. Simmetriýa boýunça S = 2∫01 (x − x³) dx = 2(1/2 − 1/4) = 1/2.
