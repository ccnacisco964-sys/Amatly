6. Integral

Integral önümiň tersi: antiwönümi tapýarys we meýdany jemläp hasaplaýarys. Bu sapakda antiwönüm, Riemann jemi we olary baglanyşdyrýan Newton–Leibniz formulasy bilen tanyşarsyň.

6.1 Düşünje

Iki esasy düşünje bar:
  • Antiwönüm. F′(x) = f(x) bolsa, F funksiýa f-iň antiwönümi diýilýär. Hemişelik sanyň önümi 0 bolany üçin antiwönümler “+ C” bilen tapawutlanýar. Kesgitlenmedik integral: ∫ f(x) dx = F(x) + C.
  • Kesgitli integral. [a; b] kesimi n deň bölege bölýäris (Δx = (b − a)/n), her bölekde bir xi* nokat alyp Riemann jemini düzýäris: Sn = Σ f(xi*)·Δx. n → ∞ bolanda jemiň limiti kesgitli integral ∫ab f(x) dx. Geometriki manysy: f-iň grafigi bilen x oky arasyndaky alamatly meýdan (x okunyň ýokarsy +, aşagy −).
Iki düşünjäni Newton–Leibniz formulasy (Matematiki analiziň esasy teoremasy) birleşdirýär: kesgitli integraly hasaplamak üçin antiwönümi tapyp, uçlardaky bahalaryň tapawudyny almak ýeterlik.

6.3 Mysal we ädimme-ädim çözgüt

Mysal 1: ∫02 x² dx integraly hasaplaň.
  1. 1-nji ädim (antiwönüm): x²-yň antiwönümi F(x) = x³/3 (sebäbi (x³/3)′ = x²).
  2. 2-nji ädim (Newton–Leibniz): F(2) − F(0) = 8/3 − 0.
  3. Netije: ∫02 x² dx = 8/3 ≈ 2.6667.
Mysal 2: ∫ (3x² − 4x + 5) dx kesgitlenmedik integraly tapyň.
  1. 1-nji ädim: Çyzyklylyk: her agzany aýry integrirleýäris.
  2. 2-nji ädim: ∫ 3x² dx = x³, ∫ (−4x) dx = −2x², ∫ 5 dx = 5x.
  3. Netije: ∫ (3x² − 4x + 5) dx = x³ − 2x² + 5x + C. Barlag: (x³ − 2x² + 5x)′ = 3x² − 4x + 5 ✓.
Mysal 3 (Riemann jemi): f(x) = x², [0; 2], n = 4. Sag we çep uçlar boýunça jemleri hasaplaň.
  1. 1-nji ädim: Δx = (2 − 0)/4 = 0.5; bölüji nokatlar 0, 0.5, 1, 1.5, 2.
  2. 2-nji ädim (çep uçlar): S₄ = 0.5·(0 + 0.25 + 1 + 2.25) = 1.75.
  3. 3-nji ädim (sag uçlar): S₄ = 0.5·(0.25 + 1 + 2.25 + 4) = 3.75.
  4. Netije: takyk baha 8/3 ≈ 2.667 iki jemiň arasynda. n artdygyça çep jem we sag jem 8/3-e ýakynlaşýar (n = 8: 2.1875 we 3.1875, orta nokatlar: 2.65625).
Mysal 4 (meýdan): y = sin x egrisi bilen x oky arasyndaky [0; π] kesimdäki meýdany tapyň.
  1. 1-nji ädim: sin x ≥ 0, şonuň üçin meýdan = ∫0π sin x dx.
  2. 2-nji ädim: antiwönüm F(x) = −cos x.
  3. Netije: F(π) − F(0) = −cos π + cos 0 = 1 + 1 = 2.

6.4 Interaktiw kalkulýator

Riemann jemi: meýdany dikdörtburçluklar bilen ýakynlaşdyrmak

[a; b] kesimi n deň bölege bölýär, her bölekde f-iň bahasy boýunça dikdörtburçluk gurýar we olaryň meýdanlarynyň jemini hasaplaýar. n artdygyça jem integrala ýakynlaşýar — tablisadan we grafikden görüp bilersiň.

Mysallar:
Mysal üçin n = 4, 8, 16, 100 bahalaryny synap gör. Çep uçlar artýan funksiýa üçin aşakdan, sag uçlar ýokardan ýakynlaşdyrýar; orta nokatlar iň takyk.

Integral hasaplaýjy: antiwönüm, Newton–Leibniz we san usuly

Integralyň görnüşine seredip usuly saýlaýar (tablisa, ornuna goýma, bölekleýin integrirlemek, ýönekeý droblar, trigonometrik toždestwolar), antiwönümi ädimme-ädim tapýar we F′(x) = f(x) deňligi bilen barlaýar. Serhetler berilse, Nýuton–Leýbnisiň formulasy F(b) − F(a) bilen takyk bahany tapýar we ony Simpson usulynyň san netijesi bilen deňeşdirýär. Antiwönümi elementar funksiýa bilen aňladylmaýan integrallar (mysal: e^(−x²)) diňe san usuly bilen hasaplanýar.

6.5 Maşk

1. ∫ (6x² + 2x) dx kesgitlenmedik integraly tapyň. — Jogaby görkez

2x³ + x² + C. Barlag: (2x³ + x²)′ = 6x² + 2x ✓.

2. ∫13 2x dx hasaplaň. — Jogaby görkez

F(x) = x²: 3² − 1² = 9 − 1 = 8.

3. ∫0π sin x dx hasaplaň. — Jogaby görkez

[−cos x] = −cos π + cos 0 = 1 + 1 = 2.

4. ∫1e (1/x) dx hasaplaň. — Jogaby görkez

[ln x] = ln e − ln 1 = 1 − 0 = 1.

5. y = x² egrisi, x oky we x = 3 gönüsi bilen çäklenen [0; 3] kesimdäki meýdany tapyň. — Jogaby görkez

6. ∫ e2x dx integraly tapyň. — Jogaby görkez

7. ∫−11 x³ dx we ∫−11 x² dx hasaplaň. — Jogaby görkez
