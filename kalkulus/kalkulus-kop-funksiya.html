11. Köp üýtgeýänli funksiýalar

Durmuşda köp ululyk birden köp sebäbe bagly: meýdan uzynlyga we ini, temperatura ýere we wagta. Bu sapakda iki üýtgeýänli z = f(x, y) funksiýalary, olaryň kesgitleniş ýaýlasyny, giňişlikdäki grafigini (üsti), derejeli egrilerini we iki üýtgeýänli limiti öwrenersiň.

11.1 Düşünje

Iki üýtgeýänli funksiýa — D tekizlik ýaýlasyndaky her (x, y) nokada bir z = f(x, y) sanyny degişli edýän düzgün. D — kesgitleniş ýaýlasy.
  • Grafik (üst): (x, y, f(x, y)) nokatlaryň köplügi — üç ölçegli giňişlikdäki üst. Mysal: z = x² + y² — aýlanma paraboloidy ("käse"), z = x² − y² — eýer görnüşli üst.
  • Derejeli egri: f(x, y) = c deňlemäniň egrisi — üstüň z = c beýiklikdäki kesigi. Kartadaky beýiklik çyzyklary (gorizontallar) ýaly: çyzyklar ýakyn bolsa — üst dik, seýrek bolsa — ýapgyt.
  • Kesgitleniş ýaýlasy: aňlatmanyň manysy bolan nokatlar: kök astynda ≥ 0, logarifm astynda > 0, maýdalawjy ≠ 0.
  • Limit: (x, y) nokat (a, b) nokada islendik ýol boýunça ýakynlaşanda f(x, y) → L. Iki ýol boýunça dürli bahalar alynsa — limit ýok. Bir üýtgeýänli ýagdaýda diňe iki ugur (çep we sag) bardy, indi tükeniksiz köp ýol bar.
  • Üznüksizlik: lim(x,y)→(a,b) f(x, y) = f(a, b). Köpagzalar, sin, cos, eˣ we olaryň kompozisiýalary kesgitleniş ýaýlasynda üznüksiz.
  • Üç üýtgeýänli w = f(x, y, z) funksiýa üçin derejeli egrileriň deregine derejeli üstler f(x, y, z) = c bolýar (mysal: x² + y² + z² = c — sferalar).

11.3 Mysal we ädimme-ädim çözgüt

Mysal 1: f(x, y) = √(9 − x² − y²) funksiýanyň kesgitleniş ýaýlasyny, bahalaryny we derejeli egrilerini tapyň.
  1. 1-nji ädim: kök astyndaky aňlatma 9 − x² − y² ≥ 0 ⇒ x² + y² ≤ 9 — merkezi (0; 0), radiusy 3 bolan tegelek.
  2. 2-nji ädim: 0 ≤ 9 − x² − y² ≤ 9 bolany üçin 0 ≤ f ≤ 3.
  3. 3-nji ädim: f = c ⇒ x² + y² = 9 − c² (0 ≤ c ≤ 3) — merkezdeş töwerekler; c = 3 bolanda bir nokat (0; 0).
  4. Netije: grafik — radiusy 3 bolan ýarym sfera.
Mysal 2: f(x, y) = x² − y² funksiýanyň derejeli egrileri.
  1. 1-nji ädim: c = 0: x² = y² ⇒ y = ±x — iki göni çyzyk.
  2. 2-nji ädim: c > 0: x² − y² = c — x okuna tarap açylýan giperbolalar; c < 0 — y okuna tarap açylýan giperbolalar.
  3. Netije: üst eýer görnüşli: x ugrunda ýokary galýar, y ugrunda aşak düşýär; (0; 0) — "eýer nokady".
Mysal 3: lim(x,y)→(0,0) xy/(x² + y²) barmy?
  1. 1-nji ädim (y = 0 ýoly): f(x, 0) = 0/x² = 0 → 0.
  2. 2-nji ädim (y = x ýoly): f(x, x) = x²/(2x²) = 1/2 → 1/2.
  3. Netije: iki ýol boýunça dürli bahalar — limit ýok.
Mysal 4: lim(x,y)→(0,0) x²y/(x² + y²) = ?
  1. 1-nji ädim: polýar koordinatalar: x = r cos θ, y = r sin θ ⇒ f = r³cos²θ sin θ / r² = r·cos²θ·sin θ.
  2. 2-nji ädim: |f| ≤ r (sebäbi |cos²θ sin θ| ≤ 1) we r → 0.
  3. Netije: gysyş teoremasy boýunça limit 0.

11.5 Maşk

1. f(x, y) = ln(x − y) funksiýanyň kesgitleniş ýaýlasyny tapyň. — Jogaby görkez

x − y > 0 ⇒ y < x — y = x göni çyzygyndan aşakdaky ýarym tekizlik (çyzygyň özi girmeýär).

2. f(x, y) = 1/(x² + y² − 4) funksiýanyň kesgitleniş ýaýlasy? — Jogaby görkez

x² + y² ≠ 4 — tekizligiň ähli nokatlary, radiusy 2 bolan töwerekden başga.

3. f(x, y) = 2x + y funksiýanyň derejeli egrileri nähili? — Jogaby görkez

2x + y = c ⇒ y = −2x + c — ýapgytlygy −2 bolan parallel göni çyzyklar; üst — tekizlik.

4. f(x, y) = x² + 4y² üçin f = 4 derejeli egri haýsy? — Jogaby görkez

x² + 4y² = 4 ⇒ x²/4 + y² = 1 — ýarym oklary 2 we 1 bolan ellips.

5. lim(x,y)→(1,2) (x² + xy) = ? — Jogaby görkez

Köpagza üznüksiz, şonuň üçin göni goýýarys: 1 + 1·2 = 3.

6. lim(x,y)→(0,0) (x² − y²)/(x² + y²) barmy? — Jogaby görkez

y = 0 ýoly: x²/x² = 1; x = 0 ýoly: −y²/y² = −1. Bahalar dürli — limit ýok.
