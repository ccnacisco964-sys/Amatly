1. Funksiýalar

Bu sapakda funksiýanyň näme aňladýandygyny, kesgitleniş we bahalar ýaýlasyny tapmagy, esasy funksiýa görnüşlerini, kompozisiýany we ters funksiýany öwrenersiň. Limit, önüm we integral şu düşünjelere daýanýar.

1.1 Düşünje

Funksiýa — x-iň her bahasyna diňe bir y bahasyny degişli edýän düzgün: y = f(x). x — garaşsyz üýtgeýän, y — garaşly üýtgeýän.
  • Kesgitleniş ýaýlasy D(f): f(x) hasaplanyp bilinýän ähli x-leriň köplügi.
  • Bahalar ýaýlasy E(f): x ähli D(f)-den geçende f(x)-iň alýan ähli y bahalary.
  • Dik çyzyk synagy: islendik dik çyzyk egrini iň köp bir nokatda kesse, egri funksiýanyň grafigi.
  • Jübüt we täk: f(−x) = f(x) — jübüt (grafik y okuna görä simmetriki); f(−x) = −f(x) — täk (başlangyç nokada görä simmetriki).
  • Kompozisiýa: (f∘g)(x) = f(g(x)) — ilki g, soň f ulanylýar.
  • Ters funksiýa f⁻¹: f-iň täsirini yzyna gaýtarýar. Diňe f bire-bir bolanda (her y-e bir x) bar; grafigi y = x çyzygyna görä simmetriki.

1.3 Mysal we ädimme-ädim çözgüt

Mysal 1: f(x) = √(x − 1)/(x − 3) funksiýanyň kesgitleniş ýaýlasyny tap.
  1. 1-nji ädim: Kök astynda otrisatel san bolmaly däl: x − 1 ≥ 0 → x ≥ 1.
  2. 2-nji ädim: Maýyr nola deň bolmaly däl: x − 3 ≠ 0 → x ≠ 3.
  3. Netije: iki şerti birleşdirýäris: D(f) = [1; 3) ∪ (3; ∞).
Mysal 2 (kompozisiýa): f(x) = x² + 1, g(x) = 2x − 3. (f∘g)(x) we (g∘f)(x) tap.
  1. 1-nji ädim: (f∘g)(x) = f(g(x)) = (2x − 3)² + 1.
  2. 2-nji ädim: Skobkany açýarys: 4x² − 12x + 9 + 1 = 4x² − 12x + 10.
  3. 3-nji ädim: (g∘f)(x) = g(f(x)) = 2(x² + 1) − 3 = 2x² − 1.
  4. Netije: f∘g ≠ g∘f — kompozisiýada tertip möhüm.
Mysal 3 (ters funksiýa): f(x) = √(x − 2) funksiýanyň ters funksiýasyny tap.
  1. 1-nji ädim: D(f) = [2; ∞), E(f) = [0; ∞). y = √(x − 2) ýazýarys.
  2. 2-nji ädim: Iki tarapy kwadrata götereris: y² = x − 2 → x = y² + 2 (y ≥ 0).
  3. 3-nji ädim: x we y orunlaryny çalyşýarys: f⁻¹(x) = x² + 2, x ≥ 0 (D(f⁻¹) = E(f)).
  4. Barlag: f⁻¹(3) = 11, f(11) = √9 = 3 ✓.

1.5 Maşk

1. f(x) = √(4 − x²) funksiýanyň kesgitleniş ýaýlasyny tap — Jogaby görkez

4 − x² ≥ 0 → x² ≤ 4 → −2 ≤ x ≤ 2. D(f) = [−2; 2].

2. f(x) = ln(x − 5)/(x − 7) funksiýanyň kesgitleniş ýaýlasyny tap — Jogaby görkez

Logarifm: x − 5 > 0 → x > 5. Maýyr: x ≠ 7. D(f) = (5; 7) ∪ (7; ∞).

3. f(x) = x + 1, g(x) = x². (f∘g)(2) we (g∘f)(2) näçe? — Jogaby görkez

f(g(2)) = f(4) = 5; g(f(2)) = g(3) = 9.

4. f(x) = x⁴ − 3x² jübütmi ýa-da täkmi? — Jogaby görkez

f(−x) = (−x)⁴ − 3(−x)² = x⁴ − 3x² = f(x) → jübüt.

5. f(x) = (x + 4)/2 funksiýanyň ters funksiýasyny tap — Jogaby görkez

y = (x + 4)/2 → x = 2y − 4. x we y orunlaryny çalyşsak f⁻¹(x) = 2x − 4.

6. f(x) = x² funksiýanyň ℝ-de ters funksiýasy barmy? — Jogaby görkez

Ýok: f(2) = f(−2) = 4, ýagny f bire-bir däl. x ≥ 0 bilen çäklesek f⁻¹(x) = √x.
