2. Limitler

Bu sapakda limitiň näme aňladýandygyny, ony nädip hasaplamalydygyny we haçan limitiň ýokdugyny öwrenersiň.

2.1 Düşünje

f(x) funksiýasynyň x → a limiti — x-iň a-a golaýlaşan (ýöne a-a deň bolmadyk) bahalarynda f(x)-iň ymtylýan bahasydyr. Möhüm ýeri: f(a)-nyň özi kesgitlenen bolmagy hökman däl — diňe a-a golaýda f(x) nirä barýandygy soralýar.
  • Ýakynlaşma tablisasy: x-i a-a çepden we sagdan golaýlaşdyryp f(x)-iň bahalaryny synlaýarys (h = 0.1; 0.01; 0.001 ...).
  • Çep we sag limit: x → a⁻ (a-dan kiçi bahalar) we x → a⁺ (a-dan uly bahalar). Limit bar bolmagy üçin ikisi deň bolmaly.
  • Çäksizlikdäki limit: x → +∞ ýa-da x → −∞ bolanda f(x)-iň ymtylýan bahasy (gorizontal asimptota).
  • Çäksiz limit: x → a bolanda f(x) → ±∞ (dik asimptota).
  • Limit ýok bolýan ýagdaýlar: çep ≠ sag (bökme), f(x) çäksizlige dürli alamatda gidýär (1/x, x → 0), ýa-da funksiýa yrgyldaýar (sin(1/x), x → 0).

2.3 Mysal we ädimme-ädim çözgüt

Mysal 1: limx→2 (x² − 4)/(x − 2) nirä deň?
  1. 1-nji ädim: x = 2 goýup görýäris: (4−4)/(2−2) = 0/0 — kesgitlenmedik forma, göni goýup bolmaz.
  2. 2-nji ädim: Sanawjyny köpeldijilere bölýäris: x² − 4 = (x − 2)(x + 2).
  3. 3-nji ädim: (x − 2) köpeldijisini gysgaldýarys (x ≠ 2 üçin dogry): f(x) = x + 2.
  4. 4-nji ädim: Indi x = 2 goýýarys: 2 + 2 = 4.
  5. Netije: limx→2 (x² − 4)/(x − 2) = 4.
Mysal 2 (konýugat): limx→0 (√(x + 1) − 1)/x nirä deň?
  1. 1-nji ädim: x = 0 goýsak 0/0 alynýar.
  2. 2-nji ädim: Sanawjyny we maýyry (√(x + 1) + 1)-e köpeldýäris: (√(x + 1) − 1)(√(x + 1) + 1) = (x + 1) − 1 = x.
  3. 3-nji ädim: f(x) = x / [x·(√(x + 1) + 1)] = 1 / (√(x + 1) + 1) (x ≠ 0).
  4. Netije: x = 0 goýsak 1/(1 + 1) = 1/2.
Mysal 3 (çäksizlikde): limx→∞ (3x² + x)/(2x² − 5) nirä deň?
  1. 1-nji ädim: Iň ýokary derejä (x²) bölýäris: (3 + 1/x)/(2 − 5/x²).
  2. 2-nji ädim: x → ∞ bolanda 1/x → 0 we 5/x² → 0.
  3. Netije: 3/2 (derejeler deň — baş koeffisiýentleriň gatnaşygy).
Mysal 4 (limit ýok): limx→0 1/x barada näme diýip bolar?
  1. 1-nji ädim: Sagdan (x → 0⁺): x = 0.1; 0.01; 0.001 üçin 1/x = 10; 100; 1000 — +∞.
  2. 2-nji ädim: Çepden (x → 0⁻): x = −0.1; −0.01; −0.001 üçin 1/x = −10; −100; −1000 — −∞.
  3. Netije: çep we sag limit dürli, şonuň üçin limit ýok (x = 0 — dik asimptota).

2.4 Interaktiw kalkulýator

Limit hasaplaýjy

Ýokardaky mysallary ýa-da öz aňlatmaňy synap gör. Kalkulýator mugallym ýaly çözýär: ilki göni goýup görýär, bolmasa kesgitsizligiň görnüşini (0/0, ∞/∞, 0·∞, ∞ − ∞, 1∞ …) anyklaýar we oňa laýyk usuly saýlaýar (köpeldijilere dagytmak, goşma aňlatma, baş derejä bölmek, Lopitalyň düzgüni …). Soňra jogaby san barlagy — h kiçelende f(a ± h)-iň ýakynlaşyşy — bilen tassyklaýar. Grafikde boş tegelek — "deşik" (funksiýa şol nokatda kesgitlenmedik), dolu nokat — funksiýanyň bahasy.

Mysallar:
Çäksizlik üçin "x →" meýdanyna inf ýa-da -inf ýaz. Bölekleýin funksiýa: x < 0 ? -1 : 1.

2.5 Maşk

1. limx→3 (x² − 9)/(x − 3) — Jogaby görkez

x² − 9 = (x−3)(x+3) → f(x) = x+3 (x≠3 üçin) → x=3 goýsak 3+3 = 6.

2. limx→0 sin(x)/x — Jogaby görkez

Bu standart trigonometrik limit — kalkulýatorda synap gör: netije 1-e ýakynlaşýar.

3. limx→∞ (2x+1)/(x+3) — Jogaby görkez

Sanawjy we maýyry x-e bölsek: (2 + 1/x)/(1 + 3/x) → x→∞ bolanda 1/x→0, galýar 2/1 = 2.

4. limx→1 (x³ − 1)/(x − 1) — Jogaby görkez

x³ − 1 = (x − 1)(x² + x + 1). Gysgaltsak x² + x + 1, x = 1 goýsak 3.

5. limx→∞ (x² + 1)/(x³ + x) — Jogaby görkez

Sanawjynyň derejesi (2) maýyrdan (3) kiçi, şonuň üçin limit 0. (Sanawjyny we maýyry x³-e bölüp barlap bolýar: (1/x + 1/x³)/(1 + 1/x²) → 0.)

6. limx→0 (1 − cos x)/x² — Jogaby görkez

Meşhur limit: 1/2. Kalkulýatorda f(x) = (1 − cos(x))/x^2, x → 0 ýazyp barla.
