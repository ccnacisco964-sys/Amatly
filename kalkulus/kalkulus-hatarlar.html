10. Hatarlar

Tükeniksiz köp sanyň jemi tükenikli san bolup bilermi? Bu sapakda sanly hatarlary, olaryň ýygnaklyk alamatlaryny we funksiýany tükeniksiz köpagza görnüşinde aňladýan Taylor hataryny öwrenersiň.

10.1 Düşünje

Sanly hatar — yzygiderligiň agzalarynyň tükeniksiz jemi: Σ aₙ = a₁ + a₂ + a₃ + … Onuň manysy bölekleýin jemler arkaly kesgitlenýär: Sₙ = a₁ + a₂ + … + aₙ.
  • Ýygnaklanýan hatar: Sₙ → S (san) bolsa, S — hataryň jemi. Sₙ çäksiz össe ýa-da durnuklaşmasa, hatar dargaýar.
  • Zerur şert: hatar ýygnaklanýan bolsa, aₙ → 0. Tersine dogry däl: garmoniki hatar Σ 1/n dargaýar, emma 1/n → 0.
  • Geometrik hatar Σ a·qⁿ: |q| < 1 bolsa jemi a/(1 − q), |q| ≥ 1 bolsa dargaýar. p-hatar Σ 1/nᵖ: p > 1 bolsa ýygnaklanýar, p ≤ 1 bolsa dargaýar.
  • Absolýut we şertli ýygnaklylyk: Σ|aₙ| ýygnaklanýan bolsa — absolýut; Σaₙ ýygnaklanýar, emma Σ|aₙ| dargaýar bolsa — şertli (mysal: 1 − 1/2 + 1/3 − … = ln 2).
  • Taylor hatary: f(x) = Σ f⁽ⁿ⁾(a)/n! · (x − a)ⁿ — funksiýany derejeli hatar (tükeniksiz köpagza) görnüşinde aňlatmak. a = 0 bolanda oňa Makloren hatary diýilýär. Hatar ýygnaklylyk radiusy R-iň içinde, ýagny |x − a| < R bolanda, f(x)-e deň.

10.3 Mysal we ädimme-ädim çözgüt

Mysal 1 (geometrik): Σn=1∞ (2/3)ⁿ = ?
  1. 1-nji ädim: ilkinji agza a₁ = 2/3, maýdalawjy q = 2/3, |q| < 1 — hatar ýygnaklanýar.
  2. 2-nji ädim: S = a₁/(1 − q) = (2/3)/(1/3) = 2.
  3. Netije: S = 2.
Mysal 2 (garmoniki hatar): Σ 1/n ýygnaklanýarmy?
  1. 1-nji ädim: aₙ = 1/n → 0, şonuň üçin n-nji agza alamaty netije bermeýär.
  2. 2-nji ädim: agzalary toparlaýarys: 1 + 1/2 + (1/3 + 1/4) + (1/5 + … + 1/8) + … ≥ 1 + 1/2 + 1/2 + 1/2 + … — her topar 1/2-den az däl.
  3. Netije: hatar dargaýar. Örän haýal: S₁₀₀₀₀₀ ≈ 12,09, ýöne Sₙ ≈ ln n + 0,5772 çäksiz ösýär.
Mysal 3 (Dalamber): Σn=0∞ 2ⁿ/n! ýygnaklanýarmy?
  1. 1-nji ädim: aₙ₊₁/aₙ = (2ⁿ⁺¹/(n + 1)!) · (n!/2ⁿ) = 2/(n + 1).
  2. 2-nji ädim: ρ = lim 2/(n + 1) = 0 < 1.
  3. Netije: hatar ýygnaklanýar; eˣ hataryndan (x = 2) jemi e² ≈ 7,389.
Mysal 4 (Leýbnis): 1 − 1/2 + 1/3 − 1/4 + … = Σ (−1)ⁿ⁺¹/n.
  1. 1-nji ädim: bₙ = 1/n kemelýär we 0-a ymtylýar — Leýbnisiň alamaty boýunça hatar ýygnaklanýar.
  2. 2-nji ädim: Σ|aₙ| = Σ 1/n dargaýar, diýmek ýygnaklylyk şertli.
  3. Netije: S = ln 2 ≈ 0,6931 (ln(1 + x) hatarynda x = 1).
Mysal 5 (Taylor): eˣ funksiýanyň 4-nji derejeli Makloren köpagzasyny düzüň we e0,5-i takmynan hasaplaň.
  1. 1-nji ädim: f⁽ᵏ⁾(x) = eˣ, şonuň üçin f⁽ᵏ⁾(0) = 1 we cₖ = 1/k!.
  2. 2-nji ädim: T₄(x) = 1 + x + x²/2 + x³/6 + x⁴/24.
  3. 3-nji ädim: T₄(0,5) = 1 + 0,5 + 0,125 + 0,0208333 + 0,0026042 = 1,6484375.
  4. Netije: e0,5 = 1,6487213…, ýalňyşlyk ≈ 0,00028. Dereje ulaldygyça ýalňyşlyk çalt kiçelýär.

10.4 Interaktiw kalkulýatorlar

Hatar: bölekleýin jemler we ýygnaklyk alamatlary

Σ aₙ hatarynyň ilkinji agzalaryny we bölekleýin jemlerini (100 000 agza çenli) hasaplaýar, ýygnaklyk alamatlaryny (n-nji agza, geometrik, Dalamber, Koşi, Leýbnis, p-hatar we garmoniki hatar bilen deňeşdirme) yzygiderli barlaýar we netijäni düşündirýär. Ýygnaklanýan hatar üçin jemi tapýar we ony tanyş hemişelikler (π²/6, ln 2, e …) bilen deňeşdirýär.

Mysallar:
Faktorial üçin factorial(n) ýa-da n! ýaz. Netijeler san taýdan alnan: alamatlar 100 000-e çenli agzalar boýunça barlanýar. Araçäk ýagdaýlarda (mysal, 1/(n·ln n)) kalkulýator anyk netije bermeýär — şonda integral alamatyny elde ulan.

Taylor köpagzasy we ýygnaklylyk radiusy

f(x) funksiýanyň a nokadyň töweregindäki Taylor köpagzasyny Tn(x) = Σ f⁽ᵏ⁾(a)/k!·(x − a)ᵏ gurýar. Koeffisiýentler takyk hasaplanýar (mümkin bolsa drob görnüşinde), ýygnaklylyk radiusy bahalandyrylýar, x₁ nokatda ýalňyşlygyň derejä görä kiçelişi görkezilýär we grafikde f bilen Tn deňeşdirilýär.

Mysallar:
Önümler simwolik däl-de, "kesilen derejeli hatarlaryň" arifmetikasy bilen takyk hasaplanýar, şonuň üçin 20-nji dereje hem çalt tapylýar. Ln üçin log(x), π üçin pi ýaz. Grafikde sary bölünen çyzyklar — ýygnaklylyk aralygynyň gyralary a ± R.

10.5 Maşk

1. Σn=0∞ (1/3)ⁿ = ? — Jogaby görkez

Geometrik hatar: a = 1, q = 1/3. S = 1/(1 − 1/3) = 3/2.

2. Σ n/(2n + 1) ýygnaklanýarmy? — Jogaby görkez

aₙ → 1/2 ≠ 0 — n-nji agza alamaty boýunça hatar dargaýar.

3. Σ 1/n³ ýygnaklanýarmy? — Jogaby görkez

p-hatar, p = 3 > 1 — ýygnaklanýar (jemi ≈ 1,2021 — Aperiniň hemişeligi).

4. Σ n!/nⁿ ýygnaklanýarmy? — Jogaby görkez

Dalamber: aₙ₊₁/aₙ = (n/(n + 1))ⁿ = 1/(1 + 1/n)ⁿ → 1/e ≈ 0,368 < 1 — ýygnaklanýar.

5. Σ 1/(n(n + 1)) = ? — Jogaby görkez

1/(n(n + 1)) = 1/n − 1/(n + 1) — teleskopik jem: Sₙ = 1 − 1/(n + 1) → 1.

6. sin x-iň 5-nji derejeli Makloren köpagzasy bilen sin(0,1)-i hasaplaň. — Jogaby görkez

T₅(x) = x − x³/6 + x⁵/120. T₅(0,1) = 0,1 − 0,000166667 + 0,0000000833 = 0,0998334 (takyk baha 0,09983341…).
