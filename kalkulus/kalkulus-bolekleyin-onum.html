12. Bölekleýin önüm

Üstüň ýapgytlygy ugra bagly: dagyň gündogara tarap ýapgytlygy bilen demirgazyga tarap ýapgytlygy dürli bolup biler. Bu sapakda bölekleýin önümleri, gradienti, ugur boýunça önümi, galtaşýan tekizligi we iki üýtgeýänli funksiýanyň ekstremumlaryny tapmagy öwrenersiň.

12.1 Düşünje

Bölekleýin önüm — iki üýtgeýänli funksiýanyň diňe bir üýtgeýjä görä önümi, beýlekisi hemişelik hasaplanýar.
  • ∂f/∂x (fx): y-i hemişelik saýyp, x boýunça adaty önüm. Geometrik manysy: üstüň y = y₀ tekizlik bilen kesigi bolan egriniň ýapgytlygy (x ugrundaky ýapgytlyk).
  • Gradient ∇f = (fx; fy) — wektor: f iň çalt artýan ugry görkezýär, uzynlygy |∇f| — şol iň uly artyş tizligi. Gradient derejeli egrä perpendikulýar.
  • Ugur boýunça önüm Dûf = ∇f · û — û birlik wektoryň ugrundaky üýtgeme tizligi. û ∇f bilen ugurdaş bolsa iň uly (|∇f|), ters bolsa iň kiçi (−|∇f|), derejeli egriniň ugrunda nol.
  • Galtaşýan tekizlik: üste (a, b, f(a, b)) nokatda galtaşýan tekizlik — bir üýtgeýänli ýagdaýdaky galtaşýan çyzygyň umumylaşdyrylmasy. Ol nokadyň töwereginde f-i çyzykly ýakynlaşdyrýar.
  • Ikinji tertipli önümler: fxx, fyy, fxy, fyx. Olar üznüksiz bolsa fxy = fyx (Kleronyň teoremasy).
  • Kritiki nokat: ∇f = 0 (ýa-da önüm ýok). Görnüşi Gessianyň kesgitleýjisi D = fxxfyy − fxy² boýunça anyklanýar: lokal minimum, lokal maksimum ýa-da eýer nokady (bir ugurda minimum, beýleki ugurda maksimum).

12.3 Mysal we ädimme-ädim çözgüt

Mysal 1: f(x, y) = x²y + 3xy² üçin fx we fy-i tapyň, (1; 2) nokatda hasaplaň.
  1. 1-nji ädim: y hemişelik: fx = 2xy + 3y².
  2. 2-nji ädim: x hemişelik: fy = x² + 6xy.
  3. Netije: fx(1, 2) = 4 + 12 = 16, fy(1, 2) = 1 + 12 = 13.
Mysal 2: f(x, y) = x² + y² funksiýanyň (1; 2) nokatda u = (3; 4) ugry boýunça önümini tapyň.
  1. 1-nji ädim: ∇f = (2x; 2y) = (2; 4).
  2. 2-nji ädim: |u| = 5, û = (3/5; 4/5).
  3. 3-nji ädim: Dûf = 2·3/5 + 4·4/5 = 22/5 = 4,4.
  4. Netije: iň uly artyş tizligi |∇f| = √20 = 2√5 ≈ 4,47 — ∇f ugrunda; 4,4 < 4,47, çünki u ∇f bilen az-kem burç emele getirýär.
Mysal 3: z = x² + y² üstüne (1; 2; 5) nokatda galtaşýan tekizligiň deňlemesi.
  1. 1-nji ädim: f(1, 2) = 5, fx(1, 2) = 2, fy(1, 2) = 4.
  2. 2-nji ädim: z = 5 + 2(x − 1) + 4(y − 2).
  3. Netije: z = 2x + 4y − 5. Barlag: f(1,1; 2,1) = 5,62, tekizlikde 5,6 — örän ýakyn.
Mysal 4: f(x, y) = x³ − 3x + y² funksiýanyň kritiki nokatlaryny tapyň we görnüşini kesgitläň.
  1. 1-nji ädim: fx = 3x² − 3 = 0 ⇒ x = ±1; fy = 2y = 0 ⇒ y = 0. Kritiki nokatlar: (1; 0) we (−1; 0).
  2. 2-nji ädim: fxx = 6x, fyy = 2, fxy = 0 ⇒ D = 12x.
  3. 3-nji ädim: (1; 0): D = 12 > 0, fxx = 6 > 0 ⇒ lokal minimum, f = −2. (−1; 0): D = −12 < 0 ⇒ eýer nokady.

12.5 Maşk

1. f(x, y) = x³y² + 5y üçin fx we fy-i tapyň. — Jogaby görkez

fx = 3x²y², fy = 2x³y + 5.

2. f(x, y) = exy üçin fxy-ni tapyň. — Jogaby görkez

fx = y·exy, fxy = exy + xy·exy = (1 + xy)exy. fyx hem şeýle (Kleronyň teoremasy).

3. f(x, y) = x² + 3y² funksiýanyň (1; 1) nokatda gradienti we iň uly artyş tizligi? — Jogaby görkez

∇f = (2x; 6y) = (2; 6), |∇f| = √40 = 2√10 ≈ 6,32.

4. f(x, y) = xy funksiýanyň (2; 3) nokatda û = (1/√2; 1/√2) ugry boýunça önümi? — Jogaby görkez

∇f = (y; x) = (3; 2). Dûf = (3 + 2)/√2 = 5/√2 ≈ 3,54.

5. z = xy üstüne (2; 3; 6) nokatda galtaşýan tekizlik? — Jogaby görkez

z = 6 + 3(x − 2) + 2(y − 3) ⇒ z = 3x + 2y − 6.

6. f(x, y) = x² + y² − 2x − 4y funksiýanyň ekstremumy? — Jogaby görkez

fx = 2x − 2 = 0, fy = 2y − 4 = 0 ⇒ (1; 2). D = 2·2 − 0 = 4 > 0, fxx = 2 > 0 ⇒ minimum f(1, 2) = −5.
