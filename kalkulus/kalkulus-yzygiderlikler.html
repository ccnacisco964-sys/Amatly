9. Yzygiderlikler

Yzygiderlik — natural sanlar bilen belgilenen sanlaryň tükeniksiz tertipli hatary: a₁, a₂, a₃, … Bu sapakda yzygiderligiň monotonlygyny, çäkliligini we limitini öwrenersiň, ýygnaklylygyň ε–N kesgitlemesine düşünersiň we rekurent yzygiderlikleri "örümçek" diagrammasy bilen derňärsiň.

9.1 Düşünje

Sanly yzygiderlik — her natural n sanyna bir aₙ hakyky sanyny degişli edýän funksiýa: a₁, a₂, a₃, … Bu ýerde aₙ — yzygiderligiň umumy agzasy, n — onuň belgisi (nomeri).
  • Anyk formula: agza n arkaly göni hasaplanýar: aₙ = 1/n → 1, 1/2, 1/3, …
  • Rekurent formula: indiki agza öňkülerden tapylýar: a₁ = 1, aₙ₊₁ = 2aₙ + 1 → 1, 3, 7, 15, … Fibonaççi yzygiderligi: F₁ = F₂ = 1, Fₙ₊₂ = Fₙ₊₁ + Fₙ.
  • Monotonlyk: ähli n üçin aₙ₊₁ ≥ aₙ bolsa — artýan, aₙ₊₁ ≤ aₙ bolsa — kemelýän. Barlamak üçin aₙ₊₁ − aₙ tapawudynyň alamatyna (ýa-da položitel agzalarda aₙ₊₁/aₙ gatnaşygyna) seredilýär.
  • Çäklilik: ähli n üçin m ≤ aₙ ≤ M bolýan m we M sanlary bar bolsa, yzygiderlik çäkli.
  • Ýygnaklylyk: n ulaldygyça aₙ belli bir L sanyna islendik takyklykda ýakynlaşsa we şol ýakynlykda galsa, yzygiderlik L-e ýygnaklanýar: lim aₙ = L. Beýle L ýok bolsa, yzygiderlik dargaýar (mysal: aₙ = n ýa-da aₙ = (−1)ⁿ).
  • Weýerştrasyň teoremasy: monoton we çäkli yzygiderlik hökman ýygnaklanýar. Ýöne diňe çäklilik ýeterlik däl: (−1)ⁿ çäkli, emma dargaýar.

9.3 Mysal we ädimme-ädim çözgüt

Mysal 1: aₙ = (2n + 1)/(n + 3) yzygiderligiň limitini tapyň, monotonlygyny barlaň we ε = 0,01 üçin N-i kesgitläň.
  1. 1-nji ädim (limit): sanawjyny we maýdalawjyny n-e bölýäris: aₙ = (2 + 1/n)/(1 + 3/n) → (2 + 0)/(1 + 0) = 2.
  2. 2-nji ädim (monotonlyk): aₙ = 2 − 5/(n + 3). n ulaldygyça 5/(n + 3) kiçelýär, şonuň üçin aₙ artýar; a₁ = 3/4 ≤ aₙ < 2 — yzygiderlik çäkli.
  3. 3-nji ädim (ε–N): |aₙ − 2| = 5/(n + 3) < 0,01 ⇔ n + 3 > 500 ⇔ n > 497.
  4. Netije: lim aₙ = 2; ε = 0,01 üçin N = 498 (n ≥ 498 bolanda ähli agzalar 1,99 bilen 2,01 aralygynda).
Mysal 2: aₙ = (−1)ⁿ yzygiderligi ýygnaklanýarmy?
  1. 1-nji ädim: agzalar: −1, 1, −1, 1, … — |aₙ| = 1, yzygiderlik çäkli.
  2. 2-nji ädim: jübüt belgili agzalar 1-e, täk belgililer −1-e deň: iki bölek yzygiderlik dürli limitlere eýe.
  3. Netije: limit ýok — yzygiderlik dargaýar. Çäklilik ýygnaklylyk üçin ýeterlik däl.
Mysal 3: aₙ = (1 + 1/n)ⁿ yzygiderligi.
  1. 1-nji ädim: a₁ = 2, a₂ = 2,25, a₁₀ ≈ 2,5937, a₁₀₀ ≈ 2,7048, a₁₀₀₀ ≈ 2,7169 — agzalar artýar.
  2. 2-nji ädim: yzygiderlik ýokardan çäkli (aₙ < 3), şonuň üçin Weýerştrasyň teoremasy boýunça ýygnaklanýar.
  3. Netije: lim (1 + 1/n)ⁿ = e ≈ 2,71828 — natural logarifmiň esasy şu limit bilen kesgitlenýär.
Mysal 4 (rekurent): a₁ = 1, aₙ₊₁ = √(2 + aₙ). Limiti tapyň.
  1. 1-nji ädim: a₂ = √3 ≈ 1,7321, a₃ ≈ 1,9319, a₄ ≈ 1,9829 — agzalar artýar.
  2. 2-nji ädim: aₙ < 2 bolsa, aₙ₊₁ = √(2 + aₙ) < √4 = 2 — yzygiderlik ýokardan çäkli. Monoton we çäkli ⇒ ýygnaklanýar.
  3. 3-nji ädim: limiti L diýip belläp, deňligiň iki tarapynda limite geçýäris: L = √(2 + L) ⇒ L² − L − 2 = 0 ⇒ L = 2 (L = −1 bolup bilmez, sebäbi aₙ > 0).
  4. Netije: lim aₙ = 2. Aşakdaky ikinji kalkulýatorda şu yzygiderligiň "örümçek" ýoluny gör.

9.4 Interaktiw kalkulýatorlar

Yzygiderligiň agzalary, monotonlygy, çäkliligi we limiti

aₙ formulasyny giriz: ilkinji agzalary tablisada görkezýär, monotonlygy we çäkliligi barlaýar, uly n-lerde agzalaryň özüni alyp barşy boýunça limiti tapýar. ε berilse, n ≥ N bolanda ähli agzalaryň L ± ε zolagynda galýan iň kiçi N-ni tapýar we grafikde şol zolagy görkezýär.

Mysallar:
Mysallar: (-1)^n/n, n! (faktorial), sqrt(n), log(n) (ln n), 2^n. Limit uly n-lerdäki (10 … 100000) bahalar boýunça san taýdan tapylýar, monotonlyk ilkinji 400 agza boýunça barlanýar.

Rekurent yzygiderlik: "örümçek" diagrammasy

aₙ₊₁ = g(aₙ) formulasy we a₁ boýunça agzalary hasaplaýar. Grafikde y = g(x) egrisi, y = x göni çyzygy we agzalaryň "örümçek" ýoly görünýär: ýol gozganmaýan nokada (g(L) = L) tarap towlansa — yzygiderlik şol nokada ýygnaklanýar. Gozganmaýan nokadyň durnuklylygy |g′(L)| boýunça kesgitlenýär.

Mysallar:
g-ni x üýtgeýjisi bilen ýaz (x = aₙ). Ýaşyl ýol: (aₙ; aₙ) nokatdan dik ugur bilen egrä (aₙ; aₙ₊₁), soň gorizontal ugur bilen y = x çyzygyna (aₙ₊₁; aₙ₊₁) — we ş.m.

9.5 Maşk

1. aₙ = (3n − 1)/(n + 2) yzygiderligiň limitini tapyň. — Jogaby görkez

Sanawjyny we maýdalawjyny n-e bölýäris: (3 − 1/n)/(1 + 2/n) → 3.

2. aₙ = n/(n + 1) artýanmy ýa-da kemelýänmi? Çäklimi? — Jogaby görkez

aₙ₊₁ − aₙ = (n + 1)/(n + 2) − n/(n + 1) = 1/((n + 1)(n + 2)) > 0 — artýan. 1/2 ≤ aₙ < 1 — çäkli, limiti 1.

3. lim (n² + 1)/(2n² − n) = ? — Jogaby görkez

n²-a bölýäris: (1 + 1/n²)/(2 − 1/n) → 1/2.

4. aₙ = 1/n² üçin ε = 0,001 bolanda N-i tapyň. — Jogaby görkez

1/n² < 0,001 ⇔ n² > 1000 ⇔ n > 31,62… Şonuň üçin N = 32.

5. aₙ = sin(n)/n yzygiderliginiň limiti näçe? — Jogaby görkez

−1/n ≤ sin(n)/n ≤ 1/n we ±1/n → 0. Gysyş teoremasy boýunça lim aₙ = 0.

6. a₁ = 2, aₙ₊₁ = (aₙ + 3/aₙ)/2 yzygiderliginiň limitini tapyň. — Jogaby görkez

L = (L + 3/L)/2 ⇒ 2L = L + 3/L ⇒ L² = 3 ⇒ L = √3 ≈ 1,7321 (agzalar položitel). Bu √3 üçin Nýutonyň usulydyr: a₂ = 1,75, a₃ ≈ 1,73214.
