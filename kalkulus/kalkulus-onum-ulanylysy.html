5. Önümiň ulanylyşy

Önümi funksiýany derňemek üçin ulanarys: nirede artýar, nirede kemelýär, iň uly we iň kiçi bahalar nirede, grafik nirede çukur ýa-da güberçek. Şeýle hem optimizasiýa, baglanyşykly tizlikler we Newton usuly bilen tanyşarsyň.

5.1 Düşünje

Önüm funksiýanyň özüni alyp barşyny görkezýär: f′(x) grafige geçirilen galtaşýan çyzygyň ýapgytlygydyr, onuň alamaty bolsa funksiýanyň ýokary ýa-da aşak gidýändigini habar berýär.
  • Monotonlyk: aralykda f′(x) > 0 bolsa f artýar ↗, f′(x) < 0 bolsa f kemelýär ↘.
  • Kritiki nokat: f′(c) = 0 bolýan ýa-da f′(c) kesgitlenmedik (f-iň özi kesgitlenen) nokat c. Lokal ekstremum diňe kritiki nokatlarda bolup biler, ýöne her kritiki nokat ekstremum däl (mysal: f(x) = x³, c = 0).
  • Lokal ekstremum: f′ alamatyny +-dan −-e çalyşsa — lokal maksimum, −-dan +-a çalyşsa — lokal minimum.
  • Egrilik: f″(x) > 0 bolsa grafik çukur (∪, galtaşýan çyzyklaryň üstünde), f″(x) < 0 bolsa güberçek (∩). Egriligiň ugry üýtgeýän nokada egrilik nokady diýilýär.
  • Optimizasiýa: berlen şertde iň uly ýa-da iň kiçi bahany tapmak (iň uly meýdan, iň az çykdajy ýaly meseleler).
  • Baglanyşykly tizlikler: birnäçe ululyk wagta görä üýtgeýär we biri-birine formula bilen baglanyşykly; birleriň tizligini bilip beýlekisiniň tizligini tapýarys.
  • Newton usuly: f(x) = 0 deňlemäniň köküni galtaşýan çyzyklaryň kömegi bilen ýakynlaşdyrmak.

5.3 Mysal we ädimme-ädim çözgüt

Mysal 1: f(x) = x³ − 3x funksiýany derňeň: ekstremum, monotonlyk, egrilik, [0; 3] kesimde iň uly we iň kiçi baha.
  1. 1-nji ädim (önüm): f′(x) = 3x² − 3 = 3(x − 1)(x + 1).
  2. 2-nji ädim (kritiki nokatlar): f′(x) = 0 ⇒ x = −1 we x = 1.
  3. 3-nji ädim (alamat): x < −1: f′(−2) = 9 > 0 (artýar); −1 < x < 1: f′(0) = −3 < 0 (kemelýär); x > 1: f′(2) = 9 > 0 (artýar).
  4. 4-nji ädim (ekstremum): x = −1-de + → −: lokal maksimum, f(−1) = −1 + 3 = 2. x = 1-de − → +: lokal minimum, f(1) = 1 − 3 = −2.
  5. 5-nji ädim (ikinji önüm): f″(x) = 6x. f″(−1) = −6 < 0 (maksimum), f″(1) = 6 > 0 (minimum). f″(0) = 0 we x = 0-da alamat − → +: egrilik nokady (0; 0); x < 0 güberçek, x > 0 çukur.
  6. 6-njy ädim ([0; 3] kesim): f(0) = 0, f(1) = −2, f(3) = 27 − 9 = 18. Iň uly baha 18 (x = 3), iň kiçi baha −2 (x = 1).
Mysal 2 (optimizasiýa): Perimetri 40 m bolan gönüburçlugyň iň uly meýdanyny tapyň.
  1. 1-nji ädim: Taraplary x we 20 − x (perimetr 2(x + 20 − x) = 40). Meýdan A(x) = x(20 − x) = 20x − x², 0 ≤ x ≤ 20.
  2. 2-nji ädim: A′(x) = 20 − 2x = 0 ⇒ x = 10.
  3. 3-nji ädim: A″(x) = −2 < 0 ⇒ maksimum. Uçlarda A(0) = A(20) = 0.
  4. Netije: iň uly meýdan A(10) = 100 m²; taraplar 10 × 10 — kwadrat.
Mysal 3 (Newton usuly): √2 sanyny f(x) = x² − 2 deňlemäniň köki hökmünde tapyň, x₀ = 1.
  1. Formula: f′(x) = 2x, şonuň üçin xn+1 = xn − (xn² − 2)/(2xn).
  2. x₁: 1 − (1 − 2)/2 = 1.5.
  3. x₂: 1.5 − (2.25 − 2)/3 = 1.5 − 0.08333… = 1.416667 (= 17/12).
  4. x₃: 17/12 − (1/144)/(17/6) = 577/408 = 1.414216.
  5. Netije: √2 = 1.41421356… — üç ädimden soň 6 dogry san.
Mysal 4 (baglanyşykly tizlikler): Tegelegiň radiusy 2 sm/s tizlik bilen ulalýar. Radius 10 sm bolanda meýdany nähili tizlik bilen ulalýar?
  1. 1-nji ädim (baglanyşyk): A = πr².
  2. 2-nji ädim (t boýunça önüm): dA/dt = 2πr · dr/dt.
  3. 3-nji ädim (goýmak): r = 10, dr/dt = 2 ⇒ dA/dt = 2π · 10 · 2 = 40π ≈ 125.66 sm²/s.

5.5 Maşk

1. f(x) = x² − 4x + 3 funksiýanyň ekstremumyny tapyň. — Jogaby görkez

f′(x) = 2x − 4 = 0 ⇒ x = 2. f″(x) = 2 > 0 ⇒ minimum: f(2) = 4 − 8 + 3 = −1. Minimum nokady (2; −1), maksimum ýok.

2. f(x) = 2x³ − 9x² + 12x funksiýanyň artýan we kemelýän aralyklaryny tapyň. — Jogaby görkez

f′(x) = 6x² − 18x + 12 = 6(x − 1)(x − 2). f′ > 0: x < 1 we x > 2 (artýar); f′ < 0: 1 < x < 2 (kemelýär). Lokal maksimum f(1) = 5, lokal minimum f(2) = 4.

3. f(x) = x⁴ − 2x² funksiýanyň egrilik nokatlaryny tapyň. — Jogaby görkez

f″(x) = 12x² − 4 = 0 ⇒ x = ±1/√3 ≈ ±0.577. Iki nokatda hem f″ alamaty üýtgeýär (x² > 1/3 bolanda +, x² < 1/3 bolanda −), şonuň üçin ikisi hem egrilik nokady: y = x²(x² − 2) = −5/9 ≈ −0.556.

4. [0; 4] kesimde f(x) = x² − 4x + 1 funksiýanyň iň uly we iň kiçi bahalaryny tapyň. — Jogaby görkez

f′(x) = 2x − 4 = 0 ⇒ x = 2. f(0) = 1, f(2) = −3, f(4) = 1. Iň uly baha 1 (x = 0 we x = 4), iň kiçi baha −3 (x = 2).

5. Newton usuly bilen √5 sanyny tapyň (f(x) = x² − 5, x₀ = 2): x₁ we x₂-ni hasaplaň. — Jogaby görkez

x₁ = 2 − (4 − 5)/4 = 2.25. x₂ = 2.25 − (5.0625 − 5)/4.5 = 2.25 − 0.013889 = 2.236111. (√5 = 2.236068…)

6. Kubuň gyrasy 3 sm/s tizlik bilen ulalýar. Gyra 5 sm bolanda göwrümi nähili tizlik bilen ulalýar? — Jogaby görkez

V = a³ ⇒ dV/dt = 3a² · da/dt = 3 · 25 · 3 = 225 sm³/s.
