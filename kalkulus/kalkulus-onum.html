4. Önüm

Bu sapakda önümiň näme aňladýandygyny, ony kesgitleme we esasy düzgünler bilen nädip tapmalydygyny, şeýle hem anyk däl berlen egriler üçin önümi nädip tapmalydygyny öwrenersiň.

4.1 Düşünje

f(x) funksiýasynyň önümi — funksiýanyň şol nokatdaky üýtgeýiş tizligidir. Grafikde bolsa ol grafige şol nokatda geçirilen galtaşýan çyzygyň ýapgytlygyny (burç koeffisiýentini) berýär. Mysal: ýoluň wagta görä funksiýasynyň önümi — tizlik.
  • Önüm kesgitleme boýunça iki nokady birleşdirýän kesiji çyzygyň ýapgytlygynyň limitidir: nokatlar golaýlaşanda kesiji çyzyk galtaşýan çyzyga öwrülýär.
  • f′(a) bar bolsa funksiýa a nokatda differensirlenýär. Differensirlenýän funksiýa şol nokatda hökman üznüksiz. Tersine dogry däl: f(x) = |x| x = 0-da üznüksiz, ýöne burç nokadynda galtaşýan çyzyk ýok, önüm hem ýok.
  • Önümi iki görnüşde ýazýarlar: f′(x) we dy/dx.

4.3 Mysal we ädimme-ädim çözgüt

Mysal 1: f(x) = x³ − 4x² + 2x funksiýanyň önümini tapyň.
  1. 1-nji ädim: Funksiýa üç agzanyň jemi/tapawudy, şonuň üçin her agzanyň önümini aýry-aýry alýarys.
  2. 2-nji ädim: (x³)′ = 3x² (derejeli düzgün).
  3. 3-nji ädim: (−4x²)′ = −4·2x = −8x (hemişelik köpeldiji + derejeli düzgün).
  4. 4-nji ädim: (2x)′ = 2.
  5. Netije: f′(x) = 3x² − 8x + 2. Mysal üçin f′(1) = 3 − 8 + 2 = −3.
Mysal 2 (köpeltmek düzgüni): f(x) = (3x + 1)·eˣ funksiýanyň önümini tapyň.
  1. 1-nji ädim: u = 3x + 1, v = eˣ; u′ = 3, v′ = eˣ.
  2. 2-nji ädim: (u·v)′ = u′v + uv′ = 3eˣ + (3x + 1)eˣ.
  3. Netije: f′(x) = (3x + 4)·eˣ.
Mysal 3 (zynjyr düzgüni): f(x) = (2x + 1)⁵ funksiýanyň önümini tapyň.
  1. 1-nji ädim: Daşky funksiýa u⁵, içki funksiýa u = 2x + 1.
  2. 2-nji ädim: Daşky önüm: 5u⁴ = 5(2x + 1)⁴; içki önüm: u′ = 2.
  3. Netije: f′(x) = 5(2x + 1)⁴ · 2 = 10(2x + 1)⁴.

4.4 Anyk däl differensirlemek

Käbir egriler y = f(x) görnüşinde ýazylmaýar, mysal x² + y² = 25 (töwerek). Şeýle ýagdaýda y-i x-iň funksiýasy hasaplap, deňligiň iki tarapyny hem x boýunça differensirleýäris we y′-y çözýäris. Esasy zat: y-e degişli agzalarda zynjyr düzgüni ulanylýar, mysal (y²)′ = 2y·y′.
F(x, y) = 0  ⇒  dy/dx = −Fx / Fy  (Fy ≠ 0)
Fx — F-iň x boýunça önümi (y hemişelik hasaplanýar), Fy — y boýunça önümi (x hemişelik hasaplanýar)
Mysal 4: x² + y² = 25 töweregine (3; 4) nokatda galtaşýan çyzygyň deňlemesini tapyň.
  1. 1-nji ädim: Nokat egrinde ýatýarmy? 3² + 4² = 9 + 16 = 25 ✓.
  2. 2-nji ädim: Iki tarapy x boýunça differensirleýäris: 2x + 2y·y′ = 0.
  3. 3-nji ädim: y′-y çözýäris: y′ = −x/y. (Formula boýunça: F = x² + y² − 25, Fx = 2x, Fy = 2y, y′ = −2x/2y.)
  4. 4-nji ädim: (3; 4) nokatda y′ = −3/4.
  5. Netije: galtaşýan çyzyk y − 4 = −(3/4)(x − 3), ýagny y = −0.75x + 6.25 (ýapgytlyk radiusa perpendikulýar).

4.6 Maşk

1. (5x² − 3x + 7)′ — Jogaby görkez

Her agzany aýratyn alýarys: 10x − 3 + 0 = 10x − 3.

2. (x·sin x)′ — Jogaby görkez

Köpeltmek düzgüni: 1·sin x + x·cos x = sin x + x·cos x.

3. (x²/(x+1))′ — Jogaby görkez

Bölmek düzgüni: (2x(x+1) − x²)/(x+1)² = (x² + 2x)/(x+1)².

4. (sin(x²))′ — Jogaby görkez

Çylşyrymly funksiýa düzgüni: daşky önüm cos(x²), içki önüm 2x → 2x·cos(x²).

5. f(x) = x² funksiýanyň x = 3 nokatdaky galtaşýan çyzygynyň deňlemesini tapyň. — Jogaby görkez

f′(x) = 2x ⇒ f′(3) = 6, f(3) = 9. y − 9 = 6(x − 3) ⇒ y = 6x − 9.

6. x² + y² = 25 töweregine (−4; 3) nokatda galtaşýan çyzygyň ýapgytlygyny tapyň. — Jogaby görkez

y′ = −x/y = −(−4)/3 = 4/3.

7. xy = 1 deňlemeden y′-y tapyň. — Jogaby görkez

Köpeltmek düzgüni bilen x boýunça differensirleýäris: y + x·y′ = 0 ⇒ y′ = −y/x (= −1/x², sebäbi y = 1/x).
