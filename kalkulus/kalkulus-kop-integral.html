13. Köp integrallar

Kesgitli integral egriniň aşagyndaky meýdany tapýardy; goşa integral üstüň aşagyndaky göwrümi, üçleýin integral bolsa jisimiň massasyny ýa-da göwrümini tapýar. Bu sapakda goşa we üçleýin integrallary yzygiderli integrirleme arkaly hasaplamagy, oblastyň görnüşini saýlamagy we polýar koordinatalara geçmegi öwrenersiň.

13.1 Düşünje

Goşa integral ∬D f(x, y) dA — D oblasty kiçijik gönüburçluklara bölüp, her birinde f·ΔA köpeltmek hasyllaryny jemlemek we bölekleri barha kiçeltmek bilen alynýan limit (iki ölçegli Riemann jemi).
  • Geometrik manysy: f ≥ 0 bolsa — D oblastyň üstündäki z = f(x, y) üstüň aşagyndaky jisimiň göwrümi; f = 1 bolsa — D-niň meýdany.
  • Fubiniň teoremasy (yzygiderli integrirleme): goşa integral iki adaty integralyň yzygiderligi hökmünde hasaplanýar — ilki içki integral (beýleki üýtgeýji hemişelik), soň daşky integral.
  • I görnüşli oblast: a ≤ x ≤ b, g₁(x) ≤ y ≤ g₂(x) — "dik zolaklar": ∫∫ … dy dx. II görnüşli: c ≤ y ≤ d, h₁(y) ≤ x ≤ h₂(y) — "gorizontal zolaklar": ∫∫ … dx dy. Käwagt integrirleme tertibini çalyşmak integraly ep-esli ýeňilleşdirýär: mysal üçin ∫01 ∫y1 ex² dx dy-da içki integral elementar funksiýalarda alynmaýar, ýöne şol üçburçlugy I görnüşde ýazsak (0 ≤ x ≤ 1, 0 ≤ y ≤ x): ∫01 ∫0x ex² dy dx = ∫01 x·ex² dx = (e − 1)/2. Kalkulýator şeýle ýagdaýda tertibi özi çalyşýar.
  • Polýar koordinatalar: tegelek, halka, sektor ýaly oblastlar üçin: x = r cos θ, y = r sin θ, dA = r dr dθ (r köpeldijisini ýatdan çykarma!).
  • Üçleýin integral ∭E f dV — üç ölçegli oblast boýunça; f = 1 bolsa E-niň göwrümi, f — dykyzlyk bolsa jisimiň massasy.
  • Ortaça baha: fort = (1/S)·∬D f dA (S — D-niň meýdany).

13.3 Mysal we ädimme-ädim çözgüt

Mysal 1 (gönüburçluk): ∬R xy dA, R = [0; 2] × [0; 3].
  1. 1-nji ädim (içki, y boýunça): ∫03 xy dy = x·[y²/2]03 = 9x/2.
  2. 2-nji ädim (daşky, x boýunça): ∫02 9x/2 dx = (9/2)·[x²/2]02 = 9.
  3. Netije: 9. (Bölünýän funksiýa: (∫02 x dx)(∫03 y dy) = 2 · 4,5 = 9.)
Mysal 2 (I görnüş): D — y = x² we y = x egrileriň arasyndaky oblast. Meýdany we ∬D x dA-ny tapyň.
  1. 1-nji ädim: kesişme: x² = x ⇒ x = 0, x = 1. [0; 1]-de x² ≤ y ≤ x.
  2. 2-nji ädim (meýdan): S = ∫01 ∫x²x dy dx = ∫01 (x − x²) dx = 1/2 − 1/3 = 1/6.
  3. 3-nji ädim: ∬ x dA = ∫01 x(x − x²) dx = 1/3 − 1/4 = 1/12.
Mysal 3 (polýar): ∬D (x² + y²) dA, D: x² + y² ≤ 4.
  1. 1-nji ädim: x² + y² = r², D: 0 ≤ r ≤ 2, 0 ≤ θ ≤ 2π, dA = r dr dθ.
  2. 2-nji ädim: ∫02π ∫02 r²·r dr dθ = ∫02π [r⁴/4]02 dθ = 4·2π.
  3. Netije: 8π ≈ 25,13.
Mysal 4 (üçleýin): x, y, z ≥ 0 we x + y + z ≤ 1 tetraedriň göwrümi.
  1. 1-nji ädim: 0 ≤ z ≤ 1 − x − y, 0 ≤ y ≤ 1 − x, 0 ≤ x ≤ 1.
  2. 2-nji ädim: ∫01−x (1 − x − y) dy = (1 − x)²/2.
  3. 3-nji ädim: ∫01 (1 − x)²/2 dx = [−(1 − x)³/6]01 = 1/6.
  4. Netije: V = 1/6.

13.4 Interaktiw kalkulýatorlar

Goşa integral: I, II görnüşli we polýar oblastlar

∬D f dA-ny mugallym ýaly ädimme-ädim çözýär: oblasty beýan edýär, içki integraly (daşky üýtgeýji hemişelik) we daşky integraly integrirlemegiň usullary bilen tapýar, serhetleri Nýuton–Leýbnis formulasy bilen goýup takyk jogap berýär (polýar halatda f(r cos θ, r sin θ)·r, cos²θ + sin²θ = 1); jogap Gauss–Ležandr san usuly bilen barlanýar. Oblastyň meýdanyny we f-iň ortaça bahasyny hem tapýar. D oblast 2D kartada we z = f(x, y) üst oblastyň üstünde 3D görnüşde çyzylýar.

Mysallar:
Daşky serhetler — san (π üçin pi). Içki serhetler daşky üýtgeýjä bagly bolup biler: I görnüşde x-e, II görnüşde y-e, polýarda θ-a (θ ýa-da t ýaz). f-i hemişe x we y arkaly ýaz — polýar ýagdaýda çalyşmany kalkulýator özi edýär.

13.5 Maşk

1. ∫01 ∫02 (x + y) dy dx = ? — Jogaby görkez

Içki: ∫02 (x + y) dy = 2x + 2. Daşky: ∫01 (2x + 2) dx = 1 + 2 = 3.

2. ∬D y dA, D: 0 ≤ x ≤ 1, 0 ≤ y ≤ x. — Jogaby görkez

∫01 ∫0x y dy dx = ∫01 x²/2 dx = 1/6.

3. Integrirleme tertibini çalşyň: ∫01 ∫x1 f(x, y) dy dx. — Jogaby görkez

Oblast: 0 ≤ x ≤ y ≤ 1 (üçburçluk). II görnüşde: 0 ≤ y ≤ 1, 0 ≤ x ≤ y ⇒ ∫01 ∫0y f(x, y) dx dy.

4. Radiusy 3 bolan tegelegiň meýdanyny polýar koordinatalarda hasaplaň. — Jogaby görkez

∫02π ∫03 r dr dθ = 2π · 9/2 = 9π.

5. z = 4 − x² − y² paraboloid bilen z = 0 tekizligiň arasyndaky göwrüm? — Jogaby görkez

Polýar: ∫02π ∫02 (4 − r²) r dr dθ = 2π·[2r² − r⁴/4]02 = 2π·4 = 8π ≈ 25,13.

6. ∭ (x + y + z) dV, E = [0; 1]³ (birlik kub). — Jogaby görkez

Simmetriýa: her agza 1/2 berýär (∭ x dV = ∫01 x dx = 1/2), jemi 3/2.
