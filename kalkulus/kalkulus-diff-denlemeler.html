14. Differensial deňlemelere giriş

Tebigatyň köp kanuny üýtgeýiş tizligi arkaly ýazylýar: ilatyň ösüşi, gyzgyn çaýyň sowamagy, radioaktiw dargama. Bu sapakda birinji tertipli differensial deňlemeleri, ugur meýdanyny, aýrylýan üýtgeýänli we çyzykly deňlemeleri çözmegi we çözgüdi Eýler hem-de Runge–Kutta usullary bilen ýakynlaşdyrmagy öwrenersiň.

14.1 Düşünje

Differensial deňleme — näbelli funksiýany we onuň önümlerini baglanyşdyrýan deňleme, mysal y′ = 2xy. Deňlemedäki iň ýokary önümiň tertibi — deňlemäniň tertibi.
  • Çözgüt — deňlemä goýlanda ony toždestwo öwürýän funksiýa. Umumy çözgüt hemişelik C-ni saklaýar (egriler maşgalasy), başlangyç şert y(x₀) = y₀ olaryň birini saýlaýar — bu Koşi meselesi.
  • Ugur meýdany: y′ = f(x, y) her (x, y) nokatda çözgüdiň ýapgytlygyny berýär. Nokatlarda kiçijik kesimler çyzsak, çözgüt egrileri şol kesimlere galtaşyp geçýär — deňlemäni çözmezden çözgütleriň görnüşini görýäris.
  • Aýrylýan üýtgeýänli deňleme: y′ = g(x)·h(y) ⇒ dy/h(y) = g(x) dx ⇒ iki tarapy integrirlemeli.
  • Çyzykly deňleme: y′ + p(x)·y = q(x) — integrirleýji köpeldiji μ(x) = e∫p dx bilen köpeldilende (μy)′ = μq bolýar.
  • Awtonom deňleme y′ = f(y): f(c) = 0 bolsa, y = c — deňagramlylyk çözgüdi. f′(c) < 0 bolsa durnukly (golaýdaky çözgütler oňa ymtylýar), f′(c) > 0 bolsa durnuksyz.
  • San usullary: çözgüdi formula bilen tapyp bolmaýan ýagdaýynda ony ädimme-ädim ýakynlaşdyrýarys: Eýler usuly galtaşýan çyzyk boýunça h ädim ätýär; gowulandyrylan Eýler we Runge–Kutta (RK4) usullary ýapgytlygy birnäçe nokatda ortalap has takyk netije berýär.

14.3 Mysal we ädimme-ädim çözgüt

Mysal 1 (aýrylýan): y′ = 2xy, y(0) = 1.
  1. 1-nji ädim: üýtgeýjileri aýyrýarys: dy/y = 2x dx.
  2. 2-nji ädim: integrirleýäris: ln|y| = x² + C ⇒ y = Aex².
  3. 3-nji ädim: y(0) = A = 1.
  4. Netije: y = ex².
Mysal 2 (çyzykly / awtonom): y′ = −2y + 4, y(0) = 0.
  1. 1-nji ädim (deňagramlylyk): −2y + 4 = 0 ⇒ y = 2; f′(y) = −2 < 0 — durnukly.
  2. 2-nji ädim: z = y − 2 üçin z′ = −2z ⇒ z = Ce−2x ⇒ y = 2 + Ce−2x.
  3. 3-nji ädim: y(0) = 2 + C = 0 ⇒ C = −2.
  4. Netije: y = 2 − 2e−2x — x ulaldygyça y → 2 (deňagramlylyga).
Mysal 3 (Eýler usuly): y′ = y, y(0) = 1, h = 0,5 — y(1)-i ýakynlaşdyryň.
  1. 1-nji ädim: y₁ = y₀ + h·y₀ = 1 + 0,5·1 = 1,5 (x₁ = 0,5).
  2. 2-nji ädim: y₂ = 1,5 + 0,5·1,5 = 2,25 (x₂ = 1).
  3. Netije: y(1) ≈ 2,25; takyk baha e ≈ 2,71828, ýalňyşlyk ≈ 0,47. h = 0,1 bilen: (1,1)¹⁰ ≈ 2,5937, ýalňyşlyk ≈ 0,12 — takmynan h-a proporsional.
Mysal 4 (logistik ösüş): y′ = y(1 − y).
  1. 1-nji ädim: deňagramlylyk: y(1 − y) = 0 ⇒ y = 0 we y = 1.
  2. 2-nji ädim: f(y) = y − y², f′(y) = 1 − 2y: f′(0) = 1 > 0 — y = 0 durnuksyz; f′(1) = −1 < 0 — y = 1 durnukly.
  3. Netije: 0 < y(0) < 1 bolsa, ilat S görnüşli egri boýunça 1-e (sygymlylyga) ýakynlaşýar: y = 1/(1 + Ae−x).

14.4 Interaktiw kalkulýatorlar

Ugur meýdany we çözgüt egrileri

y′ = f(x, y) deňlemäniň ugur meýdanyny çyzýar, berlen başlangyç nokatlardan geçýän çözgüt egrilerini RK4 usuly bilen gurýar we deňlemäniň görnüşini (awtonom, aýrylýan, çyzykly) anyklaýar. Awtonom deňlemelerde deňagramlylyk çözgütlerini we olaryň durnuklylygyny görkezýär. Grafigiň islendik ýerine bassaň, şol nokatdan geçýän täze çözgüt egrisi goşulýar.

Mysallar:
Nokatlary nokatly otur bilen aýyr: 0 1; 0 -1 — bu y(0) = 1 we y(0) = −1. Hasapla düwmesi basylan egrileri arassalaýar; täze egri goşmak üçin grafige bas.

San usullary: Eýler, gowulandyrylan Eýler we RK4

y′ = f(x, y), y(x₀) = y₀ Koşi meselesini çözýär. Deňlemäniň görnüşi tanalsa (y′ = g(x), y′ = a·y + b, aýrylýan üýtgeýänli, çyzykly, logistik), ilki analitik çözgüdi ädimme-ädim görkezýär. Soňra meseläni h ädim bilen üç san usulynda çözýär, netijeleri tablisada we grafikde deňeşdirýär, her usulyň ýalňyşlygyny we tertibini (h iki esse kiçelende ýalňyşlygyň näçe esse kiçelýändigini) hasaplaýar. Takyk çözgüt meýdany boş galsa, analitik çözgüt ulanylýar.

Mysallar:
Ädimiň uly bolmagy ýalňyşlygy köpeldýär: "h = 0,5" mysalyny "h = 0,1" bilen deňeşdir. Takyk çözgüdi boş goýsaň, deňeşdirmek üçin örän kiçi ädimli RK4 netijesi ulanylýar.

14.5 Maşk

1. y′ = 3y, y(0) = 2 Koşi meselesini çözüň. — Jogaby görkez

y = Ce3x, y(0) = C = 2 ⇒ y = 2e3x.

2. y′ = x/y, y(0) = 1 deňlemäni çözüň. — Jogaby görkez

y dy = x dx ⇒ y²/2 = x²/2 + C ⇒ y² = x² + 2C. y(0) = 1 ⇒ 2C = 1 ⇒ y = √(x² + 1).

3. y′ = y − 2 deňlemäniň deňagramlylyk çözgüdi we onuň durnuklylygy? — Jogaby görkez

y − 2 = 0 ⇒ y = 2. f′(y) = 1 > 0 — durnuksyz: y(0) > 2 bolsa çözgüt ýokary, y(0) < 2 bolsa aşak gidýär.

4. Eýler usuly: y′ = x + y, y(0) = 1, h = 0,1 — y₁ we y₂-ni tapyň. — Jogaby görkez

y₁ = 1 + 0,1·(0 + 1) = 1,1; y₂ = 1,1 + 0,1·(0,1 + 1,1) = 1,22. (Takyk: y(0,2) = 2e0,2 − 1,2 ≈ 1,2428.)

5. y = e−x funksiýa y′ + y = 0 deňlemäniň çözgüdimi? — Jogaby görkez

y′ = −e−x, y′ + y = −e−x + e−x = 0 ✓ — hawa.

6. Çaý 90 °C, otag 20 °C, T′ = −0,1(T − 20). 10 minutdan soň temperatura? — Jogaby görkez

T = 20 + 70e−0,1t; T(10) = 20 + 70/e ≈ 45,75 °C.
