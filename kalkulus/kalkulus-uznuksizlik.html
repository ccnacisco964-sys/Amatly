3. Üznüksizlik

Bu sapakda funksiýanyň bir nokatda üznüksiz bolmagynyň näme aňladýandygyny we onuň üç şertini öwrenersiň — bu düşünje Limitler bilen Önüm arasyndaky köprüdir. Soňra aralyk orta baha teoremasy (IVT) we onuň kömegi bilen deňlemäniň köküni tapmagy görersiň.

3.1 Düşünje

f(x) funksiýasy x = a nokadynda üznüksiz diýilýär, eger onuň grafigini şol nokatdan geçirende galamy kagyzdan aýyrmasaň bolýan bolsa — ýagny grafikde deşik, bökme ýa-da çäksizlige uçuş bolmasa.
  • Ähli polinomlar, sin x, cos x, eˣ hemme ýerde üznüksiz.
  • Rasional funksiýalar (drobler) maýyry 0 bolmadyk ýerlerinde üznüksiz; √x — x ≥ 0 üçin, ln x — x > 0 üçin.
  • Üznüksiz funksiýalaryň jemi, tapawudy, köpeltmek hasyly, bölegi (maýyr ≠ 0) we çylşyrymly funksiýasy hem üznüksiz.

3.2 Formula / kesgitleme (üç şert)

f üznüksiz x = a-da ⟺ limx→a f(x) = f(a)
(şu deňlik dogry bolmagy üçin üç zat gerek)
ŞertManysy
1. f(a) kesgitlenenFunksiýanyň şol nokatda bahasy bar bolmaly
2. limx→a f(x) barÇep we sag limit deň bolmaly (Limitler sapagy)
3. limx→a f(x) = f(a)Limit bilen funksiýanyň bahasy gabat gelmeli
Üznüksizlik görnüşleri (bir şert bozulsa):
• Aýrylýan — limit bar, ýöne f(a) kesgitlenmedik ýa-da limitden tapawutly (grafikde "deşik").
• Bökme — çep we sag limit dürli (grafikde "basgançak").
• Çäksiz — limit ±∞ (grafikde dik asimptota).

3.3 Mysal we ädimme-ädim çözgüt

Mysal: f(x) = (x² − 4)/(x − 2) funksiýasy x = 2 nokadynda üznüksizmi?
  1. 1-nji ädim: f(2) barla: (4−4)/(2−2) = 0/0 — kesgitlenmedik. Birinji şert bozuldy.
  2. 2-nji ädim: Limiti barla (Limitler sapagyndaky usul bilen): limx→2 f(x) = 4 — limit bar.
  3. 3-nji ädim: f(2) kesgitlenmänsoň, deňligi barlap bolmaýar.
  4. Netije: f(x), x = 2 nokadynda üznüksiz DÄL — bu aýrylýan üznüksizlik (grafikde x=2-de "deşik" bar, sebäbi (x−2) köpeldijisi gysgalyp, hemme ýerde f(x)=x+2 bolýar, diňe x=2-de kesgitlenmedik).
Mysal 2 (bölekleýin funksiýa): f(x) = x + 1 (x < 2), f(x) = k·x − 1 (x ≥ 2). k nähili bolanda f x = 2-de üznüksiz?
  1. 1-nji ädim: Çep limit: limx→2⁻ (x + 1) = 3.
  2. 2-nji ädim: f(2) = 2k − 1, sag limit hem 2k − 1.
  3. 3-nji ädim: Üznüksizlik üçin çep limit = f(2): 3 = 2k − 1.
  4. Netije: k = 2.

3.4 Aralyk orta baha teoremasy (IVT)

Aralyk orta baha teoremasy (Intermediate Value Theorem, IVT). f funksiýa [a; b] kesimde üznüksiz bolsun we N san f(a) bilen f(b)-niň arasynda ýatsyn. Onda (a; b) aralykda iň bolmanda bir c nokat bar, we f(c) = N. Başgaça aýtsak: üznüksiz funksiýa bir bahadan beýleki baha geçende ortadaky ähli bahalary alýar.
f [a; b]-de üznüksiz, N f(a) bilen f(b)-niň arasynda ⇒ ∃ c ∈ (a; b): f(c) = N
Netije (Bolzano): f(a)·f(b) < 0 ⇒ (a; b) aralykda f(x) = 0 deňlemäniň köki bar.
Ýarym bölmek (bisection) usuly: f(a)·f(b) < 0 bolsun.
1) m = (a + b)/2 ortasyny tap we f(m)-i hasapla.
2) f(m) = 0 bolsa kök tapyldy; ýogsam alamat çalşýan ýarymy — (a; m) ýa-da (m; b) — sakla.
3) Her ädimde kesimiň uzynlygy 2 esse kiçelýär. Ýeterlik kiçi bolýança gaýtala.
Üns ber: teoremada üznüksizlik hökman. f(x) = 1/x üçin f(−1) = −1 < 0 < 1 = f(1), ýöne f(c) = 0 bolýan c ýok, sebäbi funksiýa x = 0-da üzülýär.
Mysal 3: x³ − x − 1 = 0 deňlemäniň [1; 2] kesimde köküniň barlygyny görkeziň we ony ýakynlaşdyryň.
  1. 1-nji ädim: f(x) = x³ − x − 1 polinom, şonuň üçin üznüksiz. f(1) = −1 < 0, f(2) = 8 − 2 − 1 = 5 > 0. IVT boýunça (1; 2) aralykda kök bar.
  2. 2-nji ädim (m = 1.5): f(1.5) = 0.875 > 0 ⇒ kök (1; 1.5) aralykda.
  3. 3-nji ädim (m = 1.25): f(1.25) = −0.296875 < 0 ⇒ kök (1.25; 1.5) aralykda.
  4. 4-nji ädim (m = 1.375): f(1.375) = 0.224609 > 0 ⇒ kök (1.25; 1.375) aralykda.
  5. 5-nji ädim (m = 1.3125): f(1.3125) = −0.051514 < 0 ⇒ kök (1.3125; 1.375) aralykda.
  6. Netije: kök ≈ 1.3247. Kalkulýatorda ýakynlaşmany has köp ädimde görüp bilersiň.

3.5 Interaktiw kalkulýatorlar

Üznüksizlik barlaýjy

f(x) we a nokadyny ýaz — kalkulýator üç şerti aýry-aýry barlap, üznüksizlik görnüşini kesgitlär. Grafikde boş tegelek — "deşik", dolu nokat — funksiýanyň bahasy.

Mysallar:
Bölekleýin funksiýa: x < 0 ? -1 : 1 (şert ? eger dogry : eger nädogry).

Aralyk orta baha teoremasy (IVT) we ýarym bölmek usuly

Mysallar:
N = 0 bolsa f(x) = 0 deňlemäniň köküni gözleýäris. "1/x, [−1; 1]" mysalynda teorema näme üçin işlemeýändigini görersiň.
f(x)y = N (nokat — c)

3.6 Maşk

1. f(x) = x², x = 3 nokadynda üznüksizmi? — Jogaby görkez

f(3)=9, limx→3x²=9, deň — hawa, üznüksiz (ähli polinomlar hemme ýerde üznüksiz).

2. f(x) = 1/x, x = 0 nokadynda üznüksizmi? — Jogaby görkez

f(0) kesgitlenmedik, limx→0 hem ±∞ — ýok, çäksiz üznüksizlik.

3. f(x) = |x|/x, x = 0 nokadynda üznüksizmi? — Jogaby görkez

Çep limit = −1, sag limit = 1, dürli — ýok, bökme görnüşli üznüksizlik.

4. x³ + x − 1 = 0 deňlemäniň (0; 1) aralykda köküniň barlygyny görkeziň. — Jogaby görkez

f(x) = x³ + x − 1 polinom — üznüksiz. f(0) = −1 < 0, f(1) = 1 > 0. IVT boýunça (0; 1) aralykda f(c) = 0 bolýan c bar.

5. cos x = x deňlemäniň (0; 1) aralykda köküniň barlygyny görkeziň. — Jogaby görkez

g(x) = cos x − x üznüksiz. g(0) = 1 > 0, g(1) = cos 1 − 1 ≈ −0.4597 < 0. IVT boýunça (0; 1) aralykda g(c) = 0, ýagny cos c = c. Kök ≈ 0.7391.

6. f(x) = x + 1 (x < 2), f(x) = k·x − 1 (x ≥ 2). k = ? (f x = 2-de üznüksiz) — Jogaby görkez

Çep limit 3, f(2) = 2k − 1 ⇒ 3 = 2k − 1 ⇒ k = 2.
